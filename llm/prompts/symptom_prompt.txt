A user has described symptoms and wants to understand what conditions might
explain them. Using ONLY the CONTEXT passages below, produce a grounded,
ranked exploration of possible conditions.

CRITICAL RULE — what counts as a "condition":
Every entry in your ranked list MUST be a specific named disease or disorder
(e.g. "Gastritis", "GERD", "Peptic Ulcer Disease"). NEVER list an entry whose
name is just a symptom, a body region, or a general topic — for example
"Pain", "Abdominal Pain", "Stomach Pain", "Headache", "Fever", or "Cough" are
NOT conditions. They are background only: cite such passages as supporting
evidence for a real named condition, but do not give them their own entry in
the list. If a passage is only a generic symptom/topic page, do not turn it
into a condition.

CRITICAL RULE — never list a condition the patient already has:
If the PATIENT CONTEXT block lists "Existing conditions", do NOT include any of
those conditions as entries in your ranked differential list. They are
background context only — mention them only when explaining how they might
relate to the current symptoms, not as candidate diagnoses.

CRITICAL RULE — never invent patient details:
Use ONLY facts the user actually stated (in their description or the PATIENT
CONTEXT block). NEVER assume or assert an attribute the user did not give —
e.g. do not state or imply their sex, age, pregnancy status, or history if it
was not provided. If a condition depends on such an attribute, say it depends
on that factor (e.g. "if you are male…") instead of assuming it. Do not write
"you mentioned…" for anything the user did not mention.

CONTEXT:
{context}

USER SYMPTOM DESCRIPTION:
{query}

Respond with ALL of the following sections in order:

──────────────────────────────────────────
SECTION 1 — ACKNOWLEDGEMENT (only if needed)
──────────────────────────────────────────
If the user expresses fear, worry, or distress, open with ONE brief warm
sentence acknowledging it (e.g. "I understand this is worrying."). Then give
a one-sentence restatement of the key symptoms you are reasoning about.
Skip this section entirely if the user's tone is neutral or factual.

──────────────────────────────────────────
SECTION 2 — URGENCY ASSESSMENT
──────────────────────────────────────────
Before listing conditions, give ONE clear urgency label with a short rationale:

  🔴 SEEK EMERGENCY CARE NOW — if any symptom combination suggests a
     life-threatening condition (e.g. sudden severe headache + neck stiffness,
     chest pain + shortness of breath). Tell the user to call emergency services
     or go to the ER immediately. Do NOT continue to the differential.

  🟠 SEE A DOCTOR TODAY — if the symptom pattern is potentially serious and
     should not wait (e.g. high fever >3 days, severe unilateral pain, signs of
     infection). One sentence explaining why.

  🟡 SEEK CARE WITHIN 1–2 DAYS — if the symptoms warrant evaluation but are
     not immediately dangerous. One sentence explaining why.

  🟢 MONITOR AT HOME — if symptoms are mild and consistent with a self-limiting
     illness. Include specific warning signs that should prompt the user to
     escalate (e.g. "Return if fever rises above 39°C or persists beyond 3 days").

──────────────────────────────────────────
SECTION 3 — RANKED DIFFERENTIAL
──────────────────────────────────────────
List possible conditions, most plausible first. For EACH condition provide:

  a) Condition name (specific disease, not a symptom or body part)
  b) Likelihood: one plain-language phrase
     ("commonly associated" / "possible" / "less likely but worth noting")
  c) Supporting evidence: 1–2 sentences tied to the user's symptoms,
     with inline citations [n].
  d) What would make this MORE likely: one short phrase or question
     (e.g. "More likely if the headache is one-sided and throbbing")
  e) What would make this LESS likely / rule it out: one short phrase
     (e.g. "Less likely if there is no recent tick exposure or rash")

Only include conditions supported by the CONTEXT. If the context is
insufficient to support a condition, say so instead of guessing.

──────────────────────────────────────────
SECTION 4 — TARGETED FOLLOW-UP QUESTIONS
──────────────────────────────────────────
Ask the user exactly 3 specific questions that would most help narrow the
differential. Make them concrete and answerable, not generic. Prioritise
questions that would shift the ranking significantly.

Bad example (too generic): "How long have you had these symptoms?"
Good example (specific): "Is the headache worst at the back of your neck or
  behind your eyes, and does it worsen when you move your head?"

Number the questions 1–3. Do NOT ask for information already supplied in the
PATIENT CONTEXT block.

──────────────────────────────────────────
SECTION 5 — SUGGESTED NEXT STEPS
──────────────────────────────────────────
Based on the differential, list 1–3 concrete actions the user can take:
- A specific type of clinician to see (GP, ENT, neurologist, etc.)
- A simple self-care measure supported by the context, if appropriate
- One or two investigations a doctor is likely to order (e.g. "a throat swab",
  "a CBC blood test", "a chest X-ray") — only if supported by the context

Do NOT recommend specific prescription doses or treatments.

──────────────────────────────────────────
Do not diagnose. End with the required disclaimer.
